## Patch / study 03

Open `/proto/instruments/?v=4`. Pick the oscillator test sequence, music or microphone. Audio is off until Play / Enable mic is pressed. The source changes stop the previous input, and leaving the instrument releases the microphone.

- Pulse: a band controls a real DOM element's CSS scale.
- Draw: waveform bytes drive the Canvas trace.
- Spectrum: FFT bytes drive Canvas bars.
- Sculpt: a lazily loaded Three.js wire sculpture has scalar scale, warp and spin inputs.

Select an output, then a destination. Scalar ports accept any of bass/mid/high. Waveform and FFT are distinct typed array sources with dedicated destinations. Incompatible connections are disabled and explained in the status line. Amount scales visual influence, not audio volume.

The code panel follows the preset, source, mapping and amount. Canvas and Three.js helper source is shown from the same files the demo executes. The main snippet is explicitly an animation-loop excerpt and links to the full setup. Reduced-motion users get stationary visuals and live data readings.

Run `npx tsc -p proto/instruments/tsconfig.json --noEmit` from `examples/` to check this isolated study.
